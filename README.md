# PPT-Styled Web Presentation

Open `index.html` in a browser, or host this folder with any static web server.

## Edit Content

- Slide content is in `index.html`.
- Visual style is in `styles.css`.
- Charts, buttons, factory animation, and the Leaflet map are in `script.js`.
- Local images are stored in `assets/`.

## Sharing

Copy or upload the entire `ppt-styled-site` folder. The presentation uses relative image paths, so the images will keep working as long as the folder structure stays the same.

Chart.js, Leaflet, and OpenStreetMap tiles load from public CDNs, so the interactive charts and map need internet access.
